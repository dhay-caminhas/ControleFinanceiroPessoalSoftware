# Controle Financeiro Pessoal (Software)

## Status do Projeto
> 🚧 **Em desenvolvimento**

## Objetivo do Software
O **Controle Financeiro Pessoal** é uma aplicação desktop desenvolvida para auxiliar usuários no gerenciamento de suas finanças do dia a dia. O software tem como objetivo central permitir o registro, acompanhamento e visualização de entradas (receitas) e despesas, planejamento financeiro pessoal baseado em categorias, além do monitoramento de metas de economia a curto e longo prazo, promovendo uma melhor educação financeira.

## Tecnologias Aplicadas
* **Linguagem:** Java (JDK 17+)
* **Interface Gráfica:** Java Swing / AWT (NetBeans GUI Builder)
* **Banco de Dados:** MySQL
* **Conectividade:** JDBC (Java Database Connectivity)
* **Controle de Versão:** Git & GitHub

## Funcionalidades do Sistema (Requisitos)
1. **Autenticação de Usuário:** Tela de login e gerenciamento de acesso ao sistema.
2. **Dashboard Financeiro (Tela Principal):** Visão geral consolidada do saldo atual, saldo previsto, entradas e despesas do mês, além de resumos rápidos de planejamento e metas.
3. **Gestão de Entradas:** Cadastro, consulta e listagem de receitas financeiras vinculadas a categorias específicas.
4. **Gestão de Despesas:** Cadastro, consulta e listagem de despesas mensais por categorias (Moradia, Alimentação, Transporte, Saúde, Lazer, etc.).
5. **Planejamento Financeiro:** Ferramenta para gerenciar a distribuição do orçamento (necessidades, desejos e poupança).
6. **Controle de Metas:** Acompanhamento de objetivos financeiros (ex: viagem, reserva de emergência, troca de carro) com valores alvo e atuais.
7. **Relatórios Completos:** Tela unificada de consulta com o histórico detalhado de todas as movimentações e resumo financeiro geral.
